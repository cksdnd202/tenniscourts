# Courts Korea Android 앱 v7

## 사용자 화면

- 홈: 전국 공개 테니스장 목록, 검색, 지역·시군구·코트 종류·운영 주체 필터, 최근 등록순·이름순 정렬
- 지도: 웹 서비스에서 검증한 전국 지도 화면을 앱 내부에서 표시하고 테니스장 상세화면으로 연결
- 상세: 예약 오픈 규칙, 지도, 이용요금, 코트 종류, 이용시간, 방문 후기, 동일 위치의 다른 예약 정보, 부가 정보, 찜, 공유, 예약 사이트 이동
- 예약 알림: 상세화면의 각 예약 규칙에서 1일 전·10분 전 알림을 설정하고 별도 메뉴에서 전체 설정 관리
- 마이: 카카오 로그인, 알림 기기 연결, 찜한 테니스장, 최근 본 테니스장, 프로필·내 지역, 약관, 로그아웃
- 첫 실행: 검색·지도·예약 알림을 설명하는 3단계 온보딩

## 예약 알림 UX

1. 비로그인 사용자가 상세화면의 알림을 선택하면 카카오 로그인을 진행한다.
2. 해당 기기의 알림 권한과 Expo 푸시 토큰이 연결되지 않았다면 같은 흐름에서 연결한다.
3. 선택한 예약 규칙에 1일 전 또는 10분 전 구독을 저장한다.
4. Supabase Cron이 매분 운영 서버의 발송 작업을 실행한다.
5. 알림을 누르면 앱의 해당 테니스장·예약 규칙 카드로 이동한다.
6. 하단 고정 버튼으로 시설 예약 사이트를 연다.

## 검증

- 모바일 TypeScript 검사 통과
- Expo lint 통과
- Android production bundle export 통과
- 공개 앱 권한으로 테니스장 724곳, 요금, 블로그 후기, 예약 규칙 API 조회 확인
- Android 실제 기기에서 자동 예약 알림 수신 및 예약 사이트 이동 확인
