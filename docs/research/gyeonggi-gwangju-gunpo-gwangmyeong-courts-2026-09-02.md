### 등록에서 제외할 항목

군포 `중앙근린공원 테니스연습장`은 공식 시설명이 정규 테니스장이 아닌 **테니스연습장 2면**이다. 실제 경기용 코트인지 벽치기 연습장인지 명확하지 않으므로 테니스장 행으로 추가하지 않는 편이 안전하다.

### 5. 곤지암생활체육공원 A/B — 운영 여부 재확인

DB의 두 행은 `삼리 612-14`에 있으나 2026-09-02 광주시 공식 체육시설 예약 목록에는 노출되지 않았다. 현재 노출되는 곤지암읍 시설은 주소가 다른 `만선생활체육시설`이다. 따라서 만선을 곤지암 A/B의 단순 이름 변경으로 보지 않는다.

권장 절차:

1. 광주시 체육관광과에 운영 여부 확인
2. 폐장 또는 일반예약 중단이 확인되면 두 행을 비활성화
3. 확인 전에는 삭제하지 말고 예약 링크만 최신 목록과 맞지 않음을 표시

## 데이터 입력 시 주의점

- 광주시 통합예약은 월 고정일 오픈이 아니라 30일 롤링 윈도우다.
- 양벌테니스돔은 정규대관과 수시대관 규칙이 다르다.
- 군포 시민체육광장은 추첨과 잔여분 실시간 예약이 함께 존재한다.
- 군포 소규모 무료개방 시설에 시민체육광장 예약 규칙을 복제하지 않는다.
- 광명시립테니스장은 월별 공지 기반이라 과거 공지의 날짜를 영구 규칙으로 단정하지 않는다.
- 코트 재질이나 실제 면수를 공식 근거 없이 추정 입력하지 않는다.
- 기존 곤지암 A/B는 삭제보다 운영 확인 후 비활성화가 안전하다.
