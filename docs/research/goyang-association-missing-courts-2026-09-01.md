# 고양특례시테니스협회 누락 코트 조사 (2026-09-01)

> 등록 상태: 2026-09-01에 아래 4개 코트를 Courts Korea DB에 추가 완료. 예약 접수 시간과 예약 규칙은 당시 DB의 `충장테니스장` 값을 복제했다.

## 결론

협회 홈페이지에는 10개 예약 코트가 노출된다. 현재 Courts Korea DB의 고양시 데이터와 이름을 정규화해 비교하면 6개는 등록되어 있고 4개를 추가해야 한다.

### 이미 등록된 6개

- 대화코트 → `대화테니스장`
- 성라코트 → `성라테니스장`
- 중산코트 → `중산테니스장`
- 충장코트 → `충장테니스장`
- 토당코트 → `토당테니스장`
- 화정코트 → `화정테니스장, 화정별빛공원 테니스장`

### 조사 당시 추가가 필요했던 4개 (현재 등록 완료)

| 협회 표기 | 권장 DB 이름 | 주소 | 코트 구성 | 시설 유형 | 근거 수준 |
|---|---|---|---|---|---|
| 삼송유수지코트 | 삼송저류지 테니스장 | 경기도 고양시 덕양구 동산동 331 | 인조잔디 실외 5면 | 공공 | 고양시 공식 시설 현황 |
| 성사실외코트 | 성사시립테니스장 실외코트 | 경기도 고양시 덕양구 성사동 552-1 (도로명 안내: 호국로 876) | 실외 8면 | 공공 | 전체 12면 중 4면 전천후이므로 8면은 실외라는 계산 |
| 성사전천후코트 | 성사시립테니스장 전천후코트 | 경기도 고양시 덕양구 성사동 552-1 (도로명 안내: 호국로 876) | 막구조·조명 전천후 4면 | 공공/실내 취급 | 고양시 보도자료 |
| 킨텍스유수지코트 | 킨텍스저류지 테니스장 | 경기도 고양시 일산서구 대화동 2709 | 인조잔디 실외 5면 | 공공 | 고양시 공식 시설 현황 |

성사 코트의 바닥 재질은 이번에 확인한 최신 고양시 공식 시설 현황에 명시돼 있지 않았다. DB 입력 시 재질을 임의로 확정하지 않고 `미확인`으로 두는 것이 안전하다. 성사실외 8면은 공식 자료의 “전체 12면, 그중 전천후 4면”에서 산출한 값이다.

## 공통 예약 정보

4곳 모두 고양특례시테니스협회 온라인 예약 시스템을 사용한다.

| 항목 | 조사 결과 |
|---|---|
| 예약 방식 | 온라인 선착순 예약, 신용카드 결제 |
| 고양시민 익월 예약 오픈 | 매월 25일 22:00 |
| 타지역 거주자 익월 예약 오픈 | 매월 27일 07:00 |
| 실버 예약 | 매월 23일 10:00~14:00, 고양시 관내자만 문자 선착순 |
| 예약 시스템 이용 시간 | 매일 05:00~22:00 |
| 시설 이용 시간 | 06:00~22:00 |
| 이용 제한 | 1일 1회, 최대 2시간 |
| 타지역 요금 | 고양시민 요금의 50% 가산 |
| 실외 요금(2시간) | 평일 주간 8,000원 / 야간 10,400원, 주말 주간 10,000원 / 야간 13,000원 |
| 실내·전천후 요금(2시간) | 평일 주간 15,000원 / 야간 19,500원, 주말 주간 20,000원 / 야간 26,000원 |
| 취소·환불 | 당일 0%, 1~4일 전 90%, 5일 전 100%, 우천·강설 미이용 100% |
| 정기 휴무 | 공식 예약안내에 고정 휴무일 표기 없음 |

`당일 예약 가능 여부`는 공식 안내에서 명시적으로 확인되지 않았다. 익월 일괄 오픈 규칙만으로 당일 예약 불가를 확정하면 안 된다.

## 코트별 운영 메모

### 삼송저류지 테니스장

- 유수지 시설이므로 기상예비특보 발효 시 운영 중단 및 비품 철수 조치가 시행된다.
- 예약 링크: <https://www.gytennis.or.kr/daily/2>

### 성사시립테니스장 실외코트

- 전체 12면 중 전천후 4면을 제외한 8면으로 판단한다.
- 실외 요금표 적용 대상으로 정리한다.
- 예약 링크: <https://www.gytennis.or.kr/daily/5>

### 성사시립테니스장 전천후코트

- 4면 상부에 막구조와 조명시설이 설치되어 강우·혹서 등 기후 영향을 줄인 시설이다.
- 협회 홈페이지 영문 표기에서도 `Sungsa indoor tennis courts`로 안내한다.
- 실내 요금표 적용 대상으로 정리한다.
- 예약 링크: <https://www.gytennis.or.kr/daily/4>

### 킨텍스저류지 테니스장

- 유수지 시설이라 우기에는 장기간 이용 제한이 생길 수 있다.
- 협회는 호우 뒤 코트 정비·청소, 침수 및 진흙 유입을 이유로 예약 중단 공지를 한 사례가 있다.
- 예약 링크: <https://www.gytennis.or.kr/daily/8>

## DB 입력 권장값

공통:

- `basic_region`: 경기
- `basic_city`: 고양시
- `basic_district`: 덕양구 또는 일산서구
- `basic_type`: 공공
- `booking_method_online`: true
- `booking_method_phone`: false
- `booking_url`: 해당 코트의 협회 일별 예약 링크
- `operating_hours`: 06:00~22:00
- `booking_open_time`: 22:00 (관내 일반 예약 기준)
- `booking_open_days`: 25 (익월 관내 일반 예약 기준)
- `booking_rule_type`: ordinal
- `booking_max_slots`: 1
- `booking_slot_duration_minutes`: 120

주의:

- 타지역 오픈은 27일 07:00으로 별도 규칙이므로 메모/설명 필드에도 남겨야 한다.
- 당일 예약 가능 여부와 성사 코트 재질은 확인 전까지 추정 입력하지 않는다.
- 유수지 두 곳은 기상 상황에 따른 비정기 휴장을 설명에 포함한다.
